Simulates a population of agents playing prisoners dilemma. 

Each game of prisoners dilemma has 10 rounds, and agents may change their action based on the opponent's action in the previous round.
Each agent is defined by its strategy: a markov transition matrix indicating what action to take based on the opponent's previous action.

The agent population is modified over a series of generations by simulated annealing. 
- Each generation, new candidate agents are generated by randomly modifying the agents in the population
- All agents compete against each other to determine score
- Agents with highest score are kept for the next generation


See the full paper [here](https://www.aaronvanzyl.com/wp-content/uploads/2025/05/Adapting-Prisoners-Dilemma.pdf) for details.
